# frigate-xps

Второй, изолированный инстанс Frigate — только для веб-камеры компьютера XPS (Dell XPS One
2710). Заведён отдельно от основного `ha-frigate` (dvor/vorota/tambur/spalnia/axis_2100),
чтобы правки конфига этой одной камеры (или её рестарт) не задевали остальные пять.

Контекст и мотивация — `device_credentials/xps.txt` в основном репозитории `/config`
(раздел про перенос xps на отдельный Frigate).

Работает как отдельный Docker-контейнер на хосте Ультраделл (не через Supervisor addon
store — там повторная установка того же аддона не поддерживается), рядом с основным
контейнером Frigate, с доступом к тому же `/dev/dri/renderD128`.
